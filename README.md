*   **17:30 - 18:30** | **大悦城 3 楼长安大牌档（大悦城西游传记主题店）（晚餐）**

    *   条子肉点“关中六小碗”，大骨炖豆腐点“老西安砂锅”，另可点经典“传统烧三鲜”（人均约 65-80 元）。

    *   **19:15 - 19:40**：诗歌雕塑群顺路看《琵琶行》或《青莲剑歌》。
    *   **19:40 - 20:15**：提前 20 分钟（19:40）到中段盛唐密盒舞台前占位，20:00 观看【盛唐密盒】房玄龄、杜如晦的幽默问答
    *   **20:15 - 20:50**：散场后立刻往最南端开元广场移动，沿途随手买红柳烤肉或炒凉粉（人均约 40 元）。
    *   **20:55 - 21:45**：前赶到开元广场东侧护栏死守，21:30 观看尾场《唐韵不倒翁》（此场人少，易站第一排牵手）。
*   **21:45 之后** | **返回酒店**
    *   从不夜城步行街尽头（开元广场）步行至临近地铁站。
